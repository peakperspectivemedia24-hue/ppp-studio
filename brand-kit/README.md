# Brand kit (Peak Perspective Productions LLP)
Palette: cream (252,243,228), ink (26,26,26), red (198,35,40). Fonts: Anton (headlines), Inter (body). Logo always in original colours; on dark/red backgrounds use the cream tile (brand.tile()).
Setup in a fresh session: `sh brand-kit/setup.sh`, then `cd brand-kit && mkdir -p out && python3 carousel2.py` (writes out/carousel/*.png) or `python3 audio3.py && python3 reel3.py` (writes out/ppp_brand_reel_v3.mp4).
Use these as templates: copy, change the copy/numbers, keep layout rules (uniform headline size per slide, nothing clipped, footer logo on every slide).
Only verified proof points may appear: Asian Fencing Championship (Bharat Mandapam, 35+ countries, ~100K to 3.5M social reach in 12 days, our result on one event).
